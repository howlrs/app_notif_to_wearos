## 構成

| No. | 要点 |
| --- | --- |
| 1 | 表紙 |
| 2 | 監視システムが異常を検知したら、作業員の手首へ直接知らせる |
| 3 | スマホも SIM も使わず、現場の Wi-Fi だけで通知が届く |
| 4 | 初期設定は、現場番号と端末番号を入れるだけ |
| 5 | 登録後は、現場番号と端末番号が大きく表示される |
| 6 | 番号を打ち間違えても、通知が届かなくなる時計は出ない |
| 7 | 画面が消えた省電力状態でも、送信から約 1 秒で鳴り始めた |
| 8 | 「確認」されるまで、振動とアラーム音を最大 60 秒繰り返す |
| 9 | 手首を上げると、警告の内容と「確認」ボタンが表示される |
| 10 | 「確認」を押すと、振動と音はすぐに止まる |
| 11 | 配る前に、テスト通知で 1 台ずつ鳴動を確かめられる |
| 12 | エミュレーターでは、登録から警告の停止まで一通り動いた |
| 13 | Wear OS 5 では、警告が自動で全画面には表示されない |
| 14 | 届くまでの時間は、現場の Wi-Fi と実機で測る必要がある |
| 15 | 次は実機で、4 つの点を確かめる |
| 16 | アプリの配布と更新は、Google Play の内部テストで行う |
| 17 | 既存の監視システムへ組み込むため、構成を教えてください |
| 18 | 対象機種は、現場試行の前に決めたい |
| 19 | 実機と配信の準備を進め、1 現場での試行につなげる |

出典: 検証結果は [05 §3.1](../05-implementation-plan.md#31-エミュレーターでの結果2026-10-19)、決定事項は [06 §2](../06-risks-and-open-issues.md#2-要決定事項)、配信は [04](../04-operations-runbook.md)。画面は [screenshots/watch/](../screenshots/README.md)。

## 作り直し

```bash
python3 make_deck.py   # python-pptx 1.0 が必要
```

- フォントは BIZ UDPゴシック（Windows 10 以降に標準で入っている）。Mac など入っていない環境では別のフォントで表示されるため、配布には PDF も添える。
- PDF は LibreOffice（Gotenberg のコンテナ）で変換した。LibreOffice は和文と英数字の間に少し間隔を足すため、PowerPoint の表示とはわずかに違う。
- 検証結果やスクリーンショットを更新した時は、`make_slides.py` → `make_deck.py` の順に作り直す。
